# Разбор Miro-доски «69 источников трафика для SAAS продуктов»

Источник: https://miro.com/app/board/uXjVP_PkEGE=/?share_link_id=629270271916 (публичная, view-only).
Извлечено: через внутренний API доски (`/api/v1/boards/{id}/content`) — 175 виджетов: 88 текстовых, 85 линий-связей, 2 картинки. Тексты вытащены полностью (файл `miro-69-sources-raw.txt`), дерево — по смыслу (координаты в API не отдаются).

Автор доски — программа **baza.education PPP** (ссылка «Подробнее про программу» ведёт на sto.baza.education/ppp-main с utm_medium=69sources). То есть это не исследование рынка, а учебная карта: каталог каналов, которые авторы считают рабочими для SaaS.

## 2. Честная оценка карты

**Что в ней хорошо.** Полнота по «платным» каналам и по мобильным маркетплейсам — если бы у нас был мобильный SaaS с бюджетом, карта закрывала бы вопрос. Отдельно ценно, что в список попали **Chrome Web Store**, **ChatGPT-плагины**, **Discord Activities** и **маркетплейсы CRM/Shopify** — это те «полки», где лежит наш тип продукта.

**Что в ней не так для нас (и это главное).**

1. **36 из 69 каналов — платные.** Для нас это нулевой вариант: бюджета нет, а Meta/Google Ads из РФ и с картами РФ недоступны. Половина карты не применима.
2. **Карта мобильная.** ASO, App Store, Google Play, In-App сети, AppLovin/Unity/AdMob — это про приложение в сторе. У нас три **браузерных** инструмента на статике; из мобильного блока нам подходит только Chrome Web Store (и то как витрина, а не канал — проверено: у лидера ниши 582 установки за всю жизнь).
3. **Нет самого дешёвого для нас канала — органика в чужих обсуждениях.** В карте Reddit есть **только как реклама** (Reddit Ads), Quora — только Ads. А наш реальный вход — это ответы в существующих тредах и вопросах, где спрос уже сформулирован. То же с Facebook: только Ads, а не группы исполнителей/бухгалтеров.
4. **Нет каталогов-агрегаторов, которые дают вечный трафик за ноль:** AlternativeTo, Product Hunt, Hacker News, Indie Hackers, G2/Capterra, free-for.dev, GitHub awesome-списки, Firefox Add-ons, Microsoft Store, Pinterest.
5. **Нет региональных B2B-сообществ.** Для csv-to-json это критично: 92% нашего трафика — индийский GST. В карте нет ни CAclubindia, ни TaxGuru, ни индийских CA-групп. Без них половина усилий уходит в пустоту.
6. **Рискованные пункты.** «Нейро-фермы» и «порно-трафик» — для YMYL-проекта (Estate Ledger) это прямой вред репутации; для финансовых инструментов такие источники дают мусорный трафик и обнуляют доверие.

**Вывод по карте:** как учебный каталог — хороший чек-лист, чтобы не забыть каналы. Как план для нас — применимы примерно 8–10 позиций из 69, и то не в том виде, в каком они там описаны.

## 4. Практический итог

Карта подтверждает то, что мы уже выяснили своими замерами: **для браузерного микро-SaaS с нулевым бюджетом список из 69 каналов сжимается до 5–6 реальных**, и три из них в карте вообще отсутствуют (ответы в чужих обсуждениях, каталоги-агрегаторы, региональные профессиональные сообщества).

Отсюда правильный порядок действий не «пробовать всё из списка», а:
1. **csv-to-json** — 5 новых GST-страниц + ответы на CAclubindia/TaxGuru (единственный канал с доказанным спросом).
2. **pdfmerge** — сабмит расширения в Chrome Web Store (готово, не отправлено) + 5 статей в Medium/Хабр.
3. **estateledger** — 15 писем в attorney/CPA-блоги со шаблонами probate + value-комментарии в r/EstatePlanning (когда проверим доступ к Reddit).
4. **Каталоги-агрегаторы** — по одному действию в неделю: AlternativeTo, free-for.dev, awesome-списки на GitHub, Claude-плагины/ChatGPT-плагины.
5. Ничего платного, пока бесплатные не дадут ≥300 визитов/мес на проект.
