Why convert GSTR-1 JSON to Excel

The return arrives as a single JSON file with nested arrays. You cannot foot it, filter it, or send it to a client in that shape — and opening it in Notepad tells you nothing. Excel is where accountants actually check a return: sort by GSTIN, sum the taxable value per rate, compare HSN quantities against the sales register.

One row per item, not per invoice

A single invoice can carry several tax rates — clothing is the classic case, 5% and 18% under one HSN. Aggregating an invoice into one row loses the rate split, which is exactly what you need during an audit. Every sheet here is item-level: the invoice fields repeat, each item gets its own row, and the rate stays visible.

The Summary is calculated, not copied

A GSTR-1 JSON carries no totals, so the tool computes them: records, taxable value and IGST/CGST/SGST/Cess for every section, plus a TOTAL line. Compare it against the return before you file anything downstream. If a section looks wrong, you can see which sheet it came from.

Where the file goes (nowhere)

Most online GSTR-1 converters upload the file to their own server. For a client's return that means supplier GSTINs, invoice registers and turnover leave your machine — a confidentiality problem you carry, not the website. This tool has no upload step: parsing, section splitting and the XLSX build all happen in the browser tab. You can even switch the network off after the page loads and it keeps working.

What it does not do

It does not generate the JSON that the portal accepts for filing — that file must come from the official GST Offline Tool, because the portal validates its own schema. Use the Excel to JSON for GSTR-1 page if your data is in a spreadsheet and your accounting system needs JSON; use this page when you already have the JSON and need it readable.

Frequently Asked Questions

Is the client's GSTR-1 data uploaded anywhere?

No. There is no upload endpoint in this tool — it reads the file in the tab and builds the workbook locally. You can disconnect the network after the page loads and it still works.

Can I drop the ZIP from the GST portal?

Yes. The ZIP is unpacked in the browser and every JSON inside is converted. Drop several ZIPs at once and they merge into one workbook — that is how you build a full-year review file.

Which sections are covered?

B2B, B2BA, B2CL, B2CLA, B2CS, B2CSA, CDNR, CDNRA, CDNUR, EXP, EXPA, HSN, DOC, NIL, AT and ATADJ. Empty sections are skipped instead of leaving blank sheets.

Are invoice numbers and HSN codes kept intact?

Yes. HSN is written as text on purpose: 0401 stays 0401 and does not become 401. Invoice numbers with leading zeros stay as they are. Dates keep the portal's own DD-MM-YYYY format so nothing is re-interpreted.

Does it replace the GST Offline Tool?

No. The portal accepts only the JSON that the Offline Tool generates. This converter goes the other direction — JSON you already have becomes readable Excel for review, reconciliation and audit.

How large a file can it handle?

The limit is your machine's memory, not a server quota. A monthly return for a mid-size client converts instantly; a full year of ZIPs takes a few seconds and produces one workbook.

How much does it cost?

Nothing. No signup, no limit, no paywall — the tool exists because reading a GSTR-1 JSON is a weekly problem for anyone filing returns.
