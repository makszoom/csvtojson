Is my data safe?

Yes. All processing happens in your browser using Web Workers. Your CSV data is never uploaded to any server. Zero network requests after the page loads.

What is nested JSON mapping?

Instead of flat keys like {"address.city": "Moscow"}, you get nested objects: {"address": {"city": "Moscow"}}. Enable it in Settings → Nested Mapping → Dot-notation.
