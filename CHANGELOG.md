## 2026-11-06 — GSTR-1 JSON → Excel (новый инструмент) + измерение каналов

**Инструмент `/gstr1-json-to-excel`** (задеплоен, live E2E 99/99):
- `js/gstr1-core.js` — раскладка GSTR-1 JSON по 16 секциям (B2B, B2BA, B2CL, B2CLA, B2CS, B2CSA, CDNR, CDNRA, CDNUR, EXP, EXPA, HSN, DOC, NIL, AT, ATADJ). Строка = item, а не инвойс: один счёт может нести 5% и 18% под одним HSN, агрегация потеряла бы ставку.
- `Summary` считается из строк (у портала в JSON итогов нет): records, taxable, IGST/CGST/SGST/Cess по секции + TOTAL.
- Вход: `.json` и портальный `.zip` (JSZip), несколько файлов/ZIP мёржатся в одну книгу — Summary пересчитывается.
- Данные не переписываются: HSN остаётся текстом (`0401` не становится `401`), даты в формате портала `DD-MM-YYYY`, числовые поля — числами.
- Пустые секции не создают лист.
- 100% browser-side: проверено, что у всех 4 бесплатных конкурентов (finexo, erpgroup, gsttool, okaygst) файл уходит на сервер; у finexo перехвачен `POST /tools/api/convertData/convertGstr1JsonToXlsx` при тексте «right in your browser». Это и есть wedge.

**Измерение каналов:**
- `js/metrics.js`: `referrerHost()` — отправляется только домен источника (без пути и query), свой домен не считается.
- Воркер `csvtojson-metrics`: агрегирует `ev:<день>:<событие>:ref:<host>`, мусорные значения отбиваются регуляркой.
- `scripts/funnel-report.py`: новый раздел «По источникам перехода (каналы)»; ключи `type:`/`ref:` больше не засоряют разбивку по страницам.
- `privacy.html` обновлён: в отправляемом теперь указан домен источника, в «не отправляем» — полный referring URL.

**Тесты:** unit 234 PASS (+70: 57 на gstr1-core, 8 на referrer, 5 на карту сайта), E2E 99 PASS локально и на живом сайте (+29: инструмент, ZIP-merge, негативный кейс).

**Чего инструмент не делает (сознательно):** не генерирует JSON в схеме GSTR-1 портала — это по-прежнему Offline Tool. Страница говорит это прямым текстом.

Поэтому добавлен remote `origin`, локальная история запушена в отдельную ветку **`source`** (`git push origin master:source`), а `main` остался артефактом деплоя. Проверено: Pages по-прежнему `main` + `/`, статус `built`, `STATUS.md` в ветке `source` отдаётся 200. Правило записано в `STATUS.md` → «Git: где живёт какая история».
