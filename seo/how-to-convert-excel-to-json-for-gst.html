How to Convert Excel
to JSON for GST

Three steps, and a clear statement of what you get at the end: clean JSON for your ERP, API or review — not the file the portal accepts for filing. That file comes from the Offline Tool, and no converter changes that.

Step 1 — prepare the sheet

Three things make the difference between JSON you can use and JSON you have to fix by hand:

  • One header row. No merged cells, no title row above it. If the export came from Tally with a cover sheet, keep the data on its own sheet.
  • One section per sheet. B2B, B2CL, B2CS and CDNR have different columns — mixing them in one sheet gives you rows where half the fields are empty.
  • Identifiers as text. Invoice numbers, HSN codes and pincodes with leading zeros must be Text in Excel before conversion. Otherwise 00721 becomes 721 and 0401 becomes 401.

Step 2 — drop the workbook

Drag the .xlsx file into the box above. There is no "Save as CSV" step: the converter reads the workbook directly in your browser, shows a sheet picker when the book has more than one sheet, and opens on the sheet that looks like a data table rather than the title page.

Nothing is uploaded. The file is read by JavaScript in the page — you can disconnect the network after loading and the conversion still works.

Step 3 — check the preview, then download

The preview shows the JSON as it will be written. This is where you catch the two things that go wrong most often: a column that should be text but became numbers, and an empty column from a trailing formatted row. Fix the column type in the settings, then download or copy.

Frequently Asked Questions

Will the GST portal accept this JSON?

No. The portal accepts only the GSTR-1 JSON that its own Offline Tool generates, because it validates that file against its own schema. This converter produces general JSON for your ERP, API, reconciliation or review. Keep the Offline Tool for the upload itself.

Do I have to save my Excel as CSV first?

No. Drop the .xlsx workbook directly. If the book has several sheets the converter shows a sheet picker and opens on the one that looks like a data table, not the title sheet.

Why do invoice numbers lose their leading zeros?

Because spreadsheet software stores 00721 as the number 721 before any converter sees it. Keep the column as Text in Excel first, or set the column type to string in the converter. The same applies to HSN codes and pincodes.

Can I convert several months at once?

Yes. Drop several files together and either download each JSON separately or merge them into one array. Each batch counts as one conversion against the free limit.

Is my client's data uploaded anywhere?

No. Parsing, type casting and JSON generation all run in the page. There is no upload step, and the only network request is an anonymous page counter that carries no file data.
