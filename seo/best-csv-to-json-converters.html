Where the competitors are better than us

Being straight about this is cheaper than being caught out by a reader who tries both.

  • CSVJSON takes input we do not. It accepts TSV, Markdown tables, multiple tables copied out of ChatGPT, and psql/MySQL box output. If you are pasting data out of a chat window or a terminal, it is the better tool and it is free.
  • TableConvert gives you more output shapes. JSON object arrays, 2D arrays, column arrays, key-value pairs and a separate JSONLines route. Ours produces one structure with optional nesting.
  • ConvertCSV has a desktop version. Its online converter is free, and the paid desktop/CLI builds ($1299 or $4999 a year, enterprise licences) exist for people who need batch on their own machines without a browser.
  • Two of them are genuinely and permanently free. CSVJSON and TableConvert carry no counter. We allow five conversions and then ask for $5 once — that is a real difference, not a rounding error.

Where this site is different

  • The file does not leave the tab, in any input mode. This is narrower than it sounds, and it is the point: JSON Formatter converts in the browser but posts uploaded files to /service/uploadFile, and CodeBeautify states that on file upload "data traverse between server and client". So "browser-based" on their pages mostly describes pasting text. Ours covers drag-and-drop too.
  • Nested output with dot-notation. Write address.city in the column mapping and get {"address":{"city":…}}. ConvertCSV does this through / in headers; the others do not offer it.
  • Batch and ZIP. Drop several files, get one JSON each or a merged array. None of the five offer this on their free pages.
  • .xlsx directly. No "Save as CSV" detour — the workbook is read in the browser with a sheet picker.

Frequently Asked Questions

Which free CSV to JSON converter is actually free?

CSVJSON and TableConvert are free with no counter and no paywall. This site allows five conversions and then asks for a one-time $5 — the table says so in the price row rather than hiding it.

Do these converters upload my file?

It depends, and the marketing text is not enough. CSVJSON and TableConvert state processing is client-side. JSON Formatter converts in the browser but sends uploaded files to /service/uploadFile. CodeBeautify states that on file upload data travels between server and client. "Browser-based" often describes pasting text, not dropping a file.

Which one handles very large files?

CodeBeautify caps input at 1 MB, TableConvert at 10 MB. CSVJSON and ConvertCSV publish no numeric limit. Here the limit is your machine's memory — no server quota, but a very large workbook will be slow.
